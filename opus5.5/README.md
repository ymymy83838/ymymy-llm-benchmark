# 精霊使い Live2D ビューア（カメラトラッキング）

Web カメラで顔の動きを読み取って、キャラクター「精霊使い」の Live2D モデルを動かせるブラウザ用ビューアです。OBS への取り込みに対応しています。

## 使い方

1. ページを Chrome か Edge で開き、「カメラで動かす」を押します（初回はカメラの使用許可を求められます）。
2. 画面の方を向いて 1 秒ほど待つと、正面の向きが自動で合います。ずれたときは正面を向いて「正面を合わせる」（C キー）。
3. 動きの大きさ・口の開きやすさ・なめらかさは、スライダーで調整できます。

顔の向き（左右・上下・傾き）、体の傾き、まばたき（ウインク可）、視線、眉、口の開き、口の形、笑い目が反映されます。顔が映っていない間は自動モーションに切り替わります。

キー操作：<kbd>T</kbd> 開始／停止、<kbd>C</kbd> 正面合わせ、<kbd>M</kbd> 左右反転、<kbd>H</kbd> パネルの表示切替、<kbd>1</kbd>〜<kbd>3</kbd> 表示（全身・上半身・顔）、<kbd>Q</kbd> 照れ、<kbd>W</kbd> にっこり、<kbd>E</kbd> 精霊おやすみ

## プライバシー

- カメラの映像は画面に表示せず、保存も送信もしません。顔の向き・目・眉・口の形だけを、ブラウザの中で計算しています。
- 顔認識エンジン（MediaPipe）を含め、必要なものはすべて `index.html` 1 ファイルに入っています。ページは外部と一切通信せず、Content-Security-Policy で通信先をすべて禁止しています。
- 感度や正面合わせの値は、使っているブラウザの中（localStorage）にだけ保存されます。

## OBS で使う

**ブラウザソース（背景透過）**

1. OBS を `--enable-media-stream` 付きで起動します（Windows ではショートカットの「リンク先」の末尾に半角スペースを空けて追加）。
2. ソースに「ブラウザ」を追加し、「ローカルファイル」のチェックを外して、URL に `このページの URL` + `#obs` を指定します。
   - 例：`https://（ユーザー名）.github.io/（リポジトリ名）/#obs`
   - 全身を縦長で出すなら `#obs&view=full`
   - ページのパネルにある「ブラウザソースで直接読み込む」から、表示位置・感度・正面合わせを含んだ URL をコピーできます。
3. 表情を変えるときは、ブラウザソースを右クリック →「対話」で <kbd>Q</kbd>／<kbd>W</kbd>／<kbd>E</kbd>。

**ウィンドウキャプチャ**

ページの「配信表示にする」でパネルを隠し（背景がグリーンになります）、OBS のウィンドウキャプチャで取り込んで、クロマキー（緑）をかけます。キャラクターには緑色を使っていないので、きれいに抜けます。ブラウザのウィンドウは最小化したり、ほかのウィンドウで完全に隠したりしないでください（描画が止まることがあります）。

Web カメラは同時に 1 つのアプリしか使えないことが多いので、OBS の「映像キャプチャデバイス」などで同じカメラを使っていると開けません。

### URL オプション

`#` の後ろに `&` でつないで指定します（例：`#obs&view=full&mirror=0`）。

| オプション | 内容 |
| --- | --- |
| `obs` | OBS 用表示（背景透過・パネルなし・カメラ自動開始） |
| `window` | ウィンドウキャプチャ用（グリーンバック・カメラ自動開始） |
| `view=full` / `upper` / `face` | 表示範囲（全身／上半身／顔） |
| `bg=green` / `none` / `stage` | 背景 |
| `mirror=0` | 鏡写しにしない |
| `track=0` / `track=1` | カメラを自動で開始しない／する |
| `auto=0` / `phys=0` | 自動モーション／物理演算をオフ |

## 推奨環境

最新の Chrome または Edge（パソコン）。
